# N-LIC V2 — полевой тест DEV Release

Версия: 2.1.0-v2-preview (versionCode 2100). APK должен быть **Release**, подписан сертификатом N-LIC Development, но **не** официальным ключом.

## До подключения
1. Убедись, что не меняешь рабочую версию из официального релиза: новая сборка предназначена для тестов и использует DEV-подпись.
2. Проверь, что главный экран один: «Обход DPI / VPN-сервер», статус, сервер и одна кнопка подключения. Настройки открываются из шестерёнки.
3. Не отключай Google Play Protect. Не используй тестовую сборку для чувствительных данных.

## Основной стабильный путь
1. VPN-сервер: VLESS/REALITY без Bay, затем с Bay.
2. WireGuard без Bay, затем с Bay. Проверь доступность UDP, не только значение «подключено».
3. LIC-Auto: три узла, тест HTTPS, выбранный успешный сервер и переподключение после смены сети.
4. Проверь DNS, IPv4/IPv6, QUIC, YouTube/видео и браузер на Wi-Fi и мобильном интернете.
5. Проверь отсутствие прямого выхода трафика приложений при потере туннеля с **Android Always-on + Block connections without VPN** (два системных переключателя).

## Независимый новый C-движок — *строго экспериментально*
1. В режиме «Обход DPI» сначала проверь **стабильное ByeDPI**.
2. Отключись, открой «Настройки → Ядро локального обхода» и выбери «Экспериментальное N-LIC V2».
3. Подключись. Проверь DNS/HTTPS/UDP и открытие больших видео. Это локальный обход, НЕ удалённый зашифрованный VPN.
4. Выключи/включи сеть, несколько раз заверши/запусти соединение, переключись между Wi-Fi и мобильной сетью.
5. При ошибках отключись и верни в настройках **Стабильное ByeDPI**. Не допускается автоматическая подмена ядра без согласия.

## Критерии
- Ни одного падения приложения, бесконечного цикла подключения или публично слушающего SOCKS5.
- Шифрованный VPN реально переносит трафик, не просто открывает иконку Android.
- У экспериментального ядра SOCKS5 доступен только на 127.0.0.1, с временным паролем.
- При отключении/падении и включённой системной блокировке нет обхода VPN приложениями.
- Нет постоянной фоновой нагрузки после остановки, утечек ресурсов и разогрева в покое.

**Ограничения:** новые манипуляции TLS в V2 не гарантируют обход DPI у оператора. Нативный SOCKS5 использует системное DNS в локальном режиме; это может раскрывать DNS-запросы физической сети. Из-за особенностей Android, IP приложения N-LIC также исключён из собственного туннеля. Проверка на утечки и энергопотребление ещё необходима.
